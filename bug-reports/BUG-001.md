# BUG-001 — Room Reservation Pages Fail to Load

**Related Test Case:** TC-004  
**Requirement:** REQ-002  
**Acceptance Criteria:** AC-004, AC-005  
**Severity:** High  
**Suggested Priority:** High  
**Status:** Open — Portfolio Investigation  
**Environment:** Restful Booker Platform, Google Chrome

## Description

The reservation pages for Single, Double, and Suite rooms remain stuck on a loading screen after clicking Book Now. Chrome DevTools shows HTTP 500 Internal Server Error responses for all three room-detail API requests.

## Steps to Reproduce

1. Open https://automationintesting.online/
2. Navigate to the Our Rooms section.
3. Click Book Now for the Single room.
4. Wait approximately 20 seconds and observe the reservation page.
5. Repeat the process for the Double and Suite rooms.

## Expected Result

The reservation interface should load successfully for the selected room, allowing guests to proceed with booking.

## Actual Result

All three room types remain stuck on a loading screen, preventing guests from accessing the reservation interface.

The Single room loading issue was also reproduced using future reservation dates.

## API Investigation

Chrome DevTools showed the following failed requests:

**Single Room:**  
GET https://automationintesting.online/api/room/1  
Status: 500 Internal Server Error

**Double Room:**  
GET https://automationintesting.online/api/room/2  
Status: 500 Internal Server Error

**Suite Room:**  
GET https://automationintesting.online/api/room/3  
Status: 500 Internal Server Error

The Single room endpoint was also tested independently in Postman.

**Request:** GET https://automationintesting.online/api/room/1  
**Status:** 500 Internal Server Error  
**Response:** Internal Server Error

### Additional API Verification

The room-listing endpoint was tested independently in Postman.

**Request:** GET https://automationintesting.online/api/room/  
**Status:** 200 OK

The response successfully returned JSON data for all three room categories: Single (ID 1), Double (ID 2), and Suite (ID 3).

The room-listing endpoint responds successfully, while the individual room-detail endpoints return HTTP 500 errors.

This suggests the issue affects individual room-detail retrieval rather than the entire room API. The underlying cause has not been confirmed.

## Business Impact

Guests cannot access the reservation interface for any of the three displayed room types. This prevents customers from completing reservations through the affected booking workflow.
